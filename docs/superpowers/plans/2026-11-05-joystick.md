# Joystick Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the optional Overworld d-pad with an always-on joystick (bottom left) and keep the A button (bottom right), on touch screens only.

**Architecture:** A pure `stickDirection`/`knobOffset` module in `src/logic/joystick.ts` turns a thumb offset into a grid direction. `TouchControls` keeps its public API (`direction`, `takeAction()`, `setVisible()`) and swaps the 4 arrow buttons for a ring, a knob, and an invisible circular grab zone. `UI` makes the controls when Phaser reports a touch screen; the `dpad` setting and its Options item go away.

**Tech Stack:** TypeScript, Phaser 4.2.1, Vitest. Node 22.12 (`nvm use`).

Spec: `docs/superpowers/specs/2026-11-05-joystick-design.md`.

// Turns a thumb's offset from the joystick's center into one of the four grid directions, and places the knob.
import type { Direction } from './grid.ts';

export const STICK = { deadZone: 4, switchRatio: 1.25 };

export function stickDirection(dx: number, dy: number, current: Direction | null): Direction | null {
    const across = Math.abs(dx);
    const along = Math.abs(dy);

    if (Math.hypot(dx, dy) < STICK.deadZone) {
        return null;
    }

    let horizontal = across > along;
    if (current === 'left' || current === 'right') {
        horizontal = along <= across * STICK.switchRatio;
    } else if (current === 'up' || current === 'down') {
        horizontal = across > along * STICK.switchRatio;
    }

    if (horizontal) {
        return dx < 0 ? 'left' : 'right';
    }
    return dy < 0 ? 'up' : 'down';
}

export function knobOffset(dx: number, dy: number, travel: number): { x: number; y: number } {
    const scale = Math.min(1, travel / (Math.hypot(dx, dy) || 1));
    return { x: Math.trunc(dx * scale), y: Math.trunc(dy * scale) };
}
```

// A filled circle, `radius * 2` pixels across, with its bounding box's top-left at (x, y).
export function discPath(x: number, y: number, radius: number): string {
    const rows: string[] = [];

    for (let row = 0; row < radius * 2; row++) {
        const fromMiddle = row + 0.5 - radius;
        const half = Math.round(Math.sqrt(radius ** 2 - fromMiddle ** 2));
        rows.push(rectPath(x + radius - half, y + row, half * 2, 1));
    }

    return rows.join(' ');
}
```

```ts
// The on-screen controls for touch screens: a joystick at the bottom left and an A button at the bottom right.
// Drag the knob to walk; tap A to talk to whoever you face. A second finger can tap A while the thumb walks.
import { Geom, type GameObjects, type Input, type Scene, type Types } from 'phaser';
import { TEXTURES } from '../art/textures.ts';
import type { Direction } from '../logic/grid.ts';
import { knobOffset, stickDirection } from '../logic/joystick.ts';
import { colorNumber } from '../palette.ts';
import { addPixelText } from './text.ts';

const STICK = { x: 24, y: 134, grabRadius: 26, travel: 11 };
const ACTION = { x: 214, y: 118, size: 22 };

type Part = GameObjects.GameObject & GameObjects.Components.Visible;

export class TouchControls {
    direction: Direction | null = null;
    private actionQueued = false;
    private grip: number | null = null;
    private shown = true;
    private readonly base: GameObjects.Image;
    private readonly knob: GameObjects.Image;
    private readonly parts: Part[] = [];

    constructor(private readonly scene: Scene) {
        this.base = scene.add.image(STICK.x, STICK.y, TEXTURES.stickBase).setAlpha(0.7);
        this.knob = scene.add.image(STICK.x, STICK.y, TEXTURES.stickKnob).setAlpha(0.9);
        const grab = scene.add.zone(STICK.x, STICK.y, STICK.grabRadius * 2, STICK.grabRadius * 2)
            .setInteractive(new Geom.Circle(STICK.grabRadius, STICK.grabRadius, STICK.grabRadius), Geom.Circle.Contains);
        grab.on('pointerdown', (pointer: Input.Pointer, _x: number, _y: number, event: Types.Input.EventData) => {
            if (!this.shown || this.grip !== null) {
                return;
            }
            event.stopPropagation();
            this.grip = pointer.id;
            this.follow(pointer);
        });

        const action = scene.add.rectangle(ACTION.x, ACTION.y, ACTION.size, ACTION.size, colorNumber('ink'), 0.7)
            .setOrigin(0)
            .setInteractive();
        action.on('pointerdown', (_pointer: unknown, _x: number, _y: number, event: Types.Input.EventData) => {
            event.stopPropagation();
            this.actionQueued = true;
        });

        this.parts.push(this.base, this.knob, grab, action, addPixelText(scene, ACTION.x + 7, ACTION.y + 7, 'A', 'cream'));

        scene.input.on('pointermove', this.handleMove);
        scene.input.on('pointerup', this.handleUp);
        scene.input.on('pointerupoutside', this.handleUp);
        scene.events.once('shutdown', () => {
            scene.input.off('pointermove', this.handleMove);
            scene.input.off('pointerup', this.handleUp);
            scene.input.off('pointerupoutside', this.handleUp);
        });
    }

    // Returns true once per tap of the A button.
    takeAction(): boolean {
        const queued = this.actionQueued;
        this.actionQueued = false;
        return queued;
    }

    setVisible(visible: boolean): void {
        if (visible === this.shown) {
            return;
        }
        this.shown = visible;
        for (const part of this.parts) {
            part.setVisible(visible);
        }
        if (!visible) {
            this.letGo();
        }
    }

    private readonly handleMove = (pointer: Input.Pointer): void => {
        if (pointer.id === this.grip) {
            this.follow(pointer);
        }
    };

    private readonly handleUp = (pointer: Input.Pointer): void => {
        if (pointer.id === this.grip) {
            this.letGo();
        }
    };

    // Reads the pointer through this scene's camera, so the offset stays right when the camera scrolls.
    private follow(pointer: Input.Pointer): void {
        const point = this.scene.cameras.main.getWorldPoint(pointer.x, pointer.y);
        const dx = point.x - this.base.x;
        const dy = point.y - this.base.y;
        const knob = knobOffset(dx, dy, STICK.travel);

        this.knob.setPosition(this.base.x + knob.x, this.base.y + knob.y);
        this.direction = stickDirection(dx, dy, this.direction);
    }

    private letGo(): void {
        this.grip = null;
        this.direction = null;
        this.knob.setPosition(this.base.x, this.base.y);
    }
}
```

```markdown
## Joystick (2026-11-05)

1. **A joystick replaces the d-pad.** A 36-pixel ring sits at the bottom left, where the d-pad was, and the A button stays at the bottom right. You asked for the joystick at the bottom right, then picked this layout. Design: `docs/superpowers/specs/2026-11-05-joystick-design.md`.
2. **Always on, touch screens only.** The controls show when Phaser reports a touch screen (`device.input.touch`, true on phones, iPads, and touch laptops). Players with a mouse and keyboard do not see them. D-PAD left Options, and an old stored `dpad` value is ignored.
3. **Four directions.** The map moves one tile at a time, so the joystick picks up, down, left, or right. Nothing happens inside 4 pixels of the center. To change axis, the new axis must be 25% bigger than the current one, so a thumb near a diagonal does not make the player zigzag (`src/logic/joystick.ts`).
4. **Grip.** The grab area is a 26-pixel radius, bigger than the ring. After a finger grabs the joystick, the joystick follows only that finger, anywhere on the screen, until it lifts. Lifting a different finger (for example, after a tap on A) does not stop the player. The UI scene has 2 touch pointers for this.
5. **Art.** The ring and knob are pixel circles drawn in code (`discPath` in `src/art/svgPath.ts`), at 70% and 90% opacity so the map shows through.
```
